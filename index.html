1. Rounding vs Truncation

🛠️ Question 1: Predict the output of the code below, then run it to check.

▶ Show answer

7.5

The second argument tells round() to keep exactly 1 decimal place. The digit after it is 6, so the 4 rounds up to 5.

🛠️ Question 2: A value of 6.7 is processed in two ways. State the result of round(6.7) and of math.trunc(6.7), and explain why they are different.

▶ Show answer

round(6.7) gives 7; math.trunc(6.7) gives 6.

Rounding moves to the closest whole number. Truncation ignores rounding rules and simply chops off the decimal part.

2. Ceiling and Floor

🛠️ Question 4: Predict the output of the code below, then run it to check.

▶ Show answer

Ceiling always pushes up to the next whole number, no matter how small the decimal part is.

🛠️ Question 5: Predict the output of the code below, then run it to check.

▶ Show answer

19

math.floor(9.99) drops down to 9 and math.ceil(9.99) steps up to 10. 9 + 10 = 19.

🛠️ Question 6: A coach holds 16 students. 75 students are going on a trip. Write one line of code that stores the number of coaches needed in a variable called coaches_needed.

▶ Show answer 
coaches_needed = math.ceil(students / coach_capacity)   # Yields 5

75 / 16 = 4.6875. Four coaches would leave 11 students behind, so math.ceil() is needed to round up to 5. Using round() would also give 5 here, but it would fail for a value such as 4.2.

🛠️ Question 8: Write the code to simulate rolling a standard six-sided dice and store the result in a variable called roll. Include the import line.

▶ Show answer 
import random
roll = random.randint(1, 6)

A common mistake is writing random.randint(0, 6) or random.randint(1, 7). Neither matches a real dice.

🛠️ Question 9: A program uses math.floor(raw_weight) where raw_weight = 58.92. A student says round(raw_weight) would give the same result. Are they correct? Test it, then explain.

▶ Show answer

No. math.floor(58.92) gives 58, but round(58.92) gives 59.

Floor always moves down to the integer below; rounding moves to the nearest integer, which here is up.

🛠️ Question 10: A game generates a bonus code. Complete the program so that it:

  1. truncates score and stores it as base_score
  2. generates a random inclusive integer from 10 to 20 and stores it as bonus
  3. adds them together and stores the total in bonus_code
▶ Show answer 
base_score = math.trunc(score)        # 87
bonus = random.randint(10, 20)        # 10 to 20 inclusive
bonus_code = base_score + bonus       # between 97 and 107

Check: base_score is always 87, so bonus_code must fall between 97 and 107 inclusive.
